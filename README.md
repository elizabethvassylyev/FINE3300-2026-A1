# FINE3300-2026-A1
Calculator code for converting currency (CAD to USD, and vice versa).

##Summary
This code reads the Bank of Canada Exchange Rate (2026) data file in order to find the latest exchange rate. That rate is then used to convert the amount provided by the user from the base currency (determined by the user) to the other one. 

Part 1: Is written by myself without the use of AI
Part 2: The code is written by an AI model (ChatGPT Luna 6) from the prompt provided in the instructions
